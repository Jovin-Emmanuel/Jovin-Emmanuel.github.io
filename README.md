# IntelliSchedule Project Website

This website presents IntelliSchedule, a context-aware intelligent activity planning and reminder system.

## Preview Locally

Run a local web server from this folder and open `index.html`. A local server is recommended because the template loads `menu.html` and `footer.html` through JavaScript.

## Template

Built using Dr. Yen-Chia Hsu's project website template:
https://github.com/yenchiah/project-website-template

## Main Files

- `index.html`: Project website content
- `menu.html`: Navigation menu
- `footer.html`: Footer section
- `css/custom.css`: IntelliSchedule-specific styling
- `img/intellischedule-icon.png`: App icon used in the website preview
