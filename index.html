Context-Aware Intelligent Activity Planning and Reminder System

IntelliSchedule

IntelliSchedule helps users save activities and receive smarter reminders based on time, location, and availability. If a user plans to buy tomatoes and later passes near a known market, the app can recommend that place at the right moment.

Project Overview

Many reminder apps depend only on a fixed date and time. In real life, activities are often connected to where a person is and whether they are free to act. IntelliSchedule addresses this by combining saved activities, schedule time, current location, known places, and simple context rules to decide when a reminder is useful.

The project is designed for everyday activities such as shopping and errands, and for university use cases such as lectures, consultation hours, library study sessions, and staff office reminders.

Problem

Students and lecturers manage many tasks across different locations. A normal calendar can remind someone at a set time, but it cannot easily notice that the user is already passing the right place to complete a task. This causes missed opportunities, forgotten errands, and reminders that arrive when the user is busy or not near the relevant location.

Solution

IntelliSchedule stores activities with time, location, category, and notes. The decision engine checks whether a user is available, near an activity location, near a relevant known place, or close to the scheduled time. It then recommends the most useful activity instead of sending generic reminders.

Key Features

Activity Scheduling

System Architecture

IntelliSchedule is implemented as a Flutter mobile application backed by Firebase services. The app uses Firestore for activity storage, Firebase Authentication for account management, geolocation for user position, geocoding for saved activity addresses, and local notifications for reminders.

Demo Flow

  1. Create activity: The user saves an activity such as "Buy tomatoes" and selects a category, date, time, and location.
  2. Read context: The app checks the user's location and availability state.
  3. Match opportunity: The decision engine compares the activity with nearby known places such as markets, grocery shops, lecture halls, and offices.
  4. Notify user: If the user is available and near a relevant place, the app sends a helpful recommendation.
  5. Complete activity: The user can mark the activity as completed from the schedule screen.
